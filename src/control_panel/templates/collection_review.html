How to recover (any backup tool)
  1. Copy the affected paths with the Copy paths button above (relative to the collection root, or full paths).
  2. In your backup tool, restore exactly those paths to the collection root {{ c.root }}.
  3. Run Scan now on the collection page. Every file that reappeared is re-read and compared against the fingerprint recorded before it went missing: a file whose contents match flips back to restored / OK; a file whose contents differ is flagged came back changed, which closes the obsolete missing alert and raises a new one in its place — check that one before you trust it.
  4. For anything you don't want back, Accept all changes to clear it from tracking.

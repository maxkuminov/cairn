{# How a pattern is read. One statement of the grammar for the operator, in examples. #}
NOTES.md
a name with no slash: every file with that name, in any folder
clients/acme/NOTES.md
a path: exactly that file, counted from the collection's folder
exports/
a trailing slash: everything in that folder, at any depth
clients/*/NOTES.md
* is any run of characters within one name, ? exactly one
**/cache/**
** as a folder of its own: any number of folders, including none
Upper and lower case matter. Everything else matches only itself — there are no character classes and no escapes.

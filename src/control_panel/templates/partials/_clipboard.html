{# The panel's ONE clipboard implementation, included once from base.html so every copy control on every page shares it and the surfaces cannot drift apart. `navigator.clipboard` is undefined outside a secure context, and plain http on a LAN address is the normal self-hosted deployment — so a bare `navigator.clipboard && …writeText(…)` is a silent no-op exactly where Cairn usually runs. Worse than doing nothing: the operator pastes whatever was already on their clipboard into a backup tool or an evidence bundle. Hence the fallback, and hence the visible result — a copy that failed has to say so. Usage: `cairnCopy(text, "id-of-a-note-span")`. #}
